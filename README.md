# Бот сторис «Авангард Строй» — первая серверная версия

**Текущий выбор пользователя: бесплатное размещение без карты. Telegram-бот создан: @avangardstories_bot. Для этого варианта используйте [FREE-HOSTING.md](FREE-HOSTING.md), `render.yaml` и `Dockerfile.render`. Инструкции Docker Compose ниже относятся к отдельному серверу с постоянным диском.**

Бот ищет проект на `old.avgst.ru`, загружает его оригинальные фото и планировку, готовит сценарий, принимает правки и оформляет PNG. Генерации изображений, перекрашивания и дорисовки нет. За основу оформления взята одобренная серия «Сканди 78».

## Что уже реализовано

- Группы, личный чат владельца, отдельные серии для каждой темы форума Telegram.
- Русские команды: `текст:`, `редакт:`, `пришли картинками`, `правка:`.
- Ответ на конкретную картинку или сценарий, выбор серии через `#номер`.
- Поиск проектов через карту сайта и оригиналы из галереи конкретного проекта.
- Текст и подбор оригиналов с помощью модели; оформление обычным кодом, без генерации картинок.
- Четыре композиции: фото, сравнение трёх фото, полная планировка, фрагмент плана.
- Сохранение исходников, источников, настроек и версий в постоянном хранилище.
- Настройки каждого чата: правила, источник, логотип, шрифты, примеры и антипримеры.
- Правки одного слайда сохраняют остальные слайды; после команды «правка» отправляются только изменённые.
- PNG без сжатия командой `исходники`.
- Лимит подготовки сценариев и правок, допуск чатов владельцем, изменение настроек администраторами.
- Очередь входящих команд переживает перезапуск, применённая правка повторно к тексту не применяется. При обрыве во время отправки Telegram может получить повторное сообщение; строго однократная внешняя отправка не обещается.

## Что требуется для настоящего запуска

1. Создать бота у официального [@BotFather](https://t.me/BotFather): `/newbot`, имя, свободное имя пользователя с окончанием `bot`. Токен вводится на сервере скрытым вводом, а не в общий чат.
2. Подключить доступный вашему аккаунту OpenAI API и оплату API. Ключ хранится только в `.env`. Модель задаётся переменной `OPENAI_MODEL`, по умолчанию `gpt-5-mini`; реальный доступ к ней проверяется после подключения ключа. Подписка в приложении и API-подключение — разные настройки; не предполагается, что ключ уже есть.
3. Создать сервер с Linux и Docker Compose. Для старта предлагается 1–2 vCPU, 2 ГБ памяти и 30 ГБ диска. Входящий веб-порт и домен не требуются: бот использует исходящие HTTPS-запросы и long polling.
4. Перед переносом проверить доступ к API и сайту с выбранного сервера. География сервера сама по себе не подтверждает право доступа аккаунта к сервису. [Поддерживаемые страны API](https://developers.openai.com/api/docs/supported-countries).

## Запуск на сервере

Перенесите эту папку на сервер. Не переносите `.venv`, `.tmp` и ненужные локальные экспорты.

```sh
python3 configure.py
docker compose up -d --build
docker compose logs --tail=50 bot
```

Если ваш числовой Telegram ID пока неизвестен, при настройке оставьте `0`. Запустите бота и отправьте ему `/id` в личном чате. Добавьте полученное число в `OWNER_TELEGRAM_ID` файла `.env`, затем:

```sh
docker compose up -d --force-recreate
```

В таком первоначальном режиме подготовка текстов отключена: посторонние пользователи не смогут потратить API-бюджет.

Настройка `.env` при необходимости вручную: скопировать `.env.example` в `.env`, заполнить значения, выставить `chmod 600 .env`. Не добавлять `.env` в архивы проекта или репозиторий.

## Подключение группы

1. Для обычных сообщений вроде «текст: …» отключите Group Privacy через `/setprivacy` в BotFather, затем заново добавьте бота в группу. Альтернатива — выдать боту права администратора. Бот должен иметь права отправлять текст, фото и файлы. [Пояснение Telegram](https://core.telegram.org/bots/features#privacy-mode).
2. Владелец отправляет `/enable` в группе. До этого платные действия в ней не работают.
3. Отправьте `текст: 6 сторис про Сканди 78`.
4. Ответом на сценарий: `редакт: на шестом слайде попроси написать Сканди 78 в директ`.
5. Ответом на сценарий: `пришли картинками`.
6. Ответом на картинку: `правка: увеличь заголовок`.
7. Для скачивания PNG: `исходники #1` (номер своей серии).

Если серий несколько, бот просит явно выбрать серию. Привязки никогда не переходят между чатами или темами форума. Редактирование уже отправленного сообщения Telegram само по себе сценарий не меняет — используйте отдельное сообщение `редакт:`.

## Настройки в чате

Администраторы и владелец могут отправлять:

```text
настройки: обращайся на «вы», не используй восклицательные знаки
источник: https://old.avgst.ru
```

Файлы отправляются с точной подписью:

| Подпись | Что отправить |
|---|---|
| логотип | PNG с прозрачностью или другое растровое изображение |
| шрифт заголовка | TTF / OTF |
| шрифт текста | TTF / OTF |
| пример | Изображение понравившегося оформления |
| не надо | Изображение нежелательного оформления |

`/settings` показывает сохранённые правила. Новые настройки применяются к новым сериям, а существующие серии сохраняют снимок настроек. Примеры и антипримеры передаются модели для подбора композиции; отрисовка ограничена четырьмя текущими макетами. Произвольная новая графическая система не создаётся автоматически. Цвета и сложные изменения фона пока задаются в `assets/brand.json` и коде макета; текстовое правило не гарантирует изменения параметра, который не предусмотрен макетом.

Начальные шрифты — Arial/Arial Black с компьютера пользователя, как в одобренной пробной серии. Пакет предназначен для личного развёртывания владельца; перед публичным распространением подставьте шрифты с подходящей лицензией.

## Смена сайта

Старый сайт подключён отдельным адаптером. Адрес и разрешённые хосты задаются в `.env` и настройках чата. Новый домен сначала добавляется в `ALLOWED_SOURCE_HOSTS` владельцем сервера, затем меняется источник. Если структура нового сайта другая, нужно адаптировать `source.py`; бот не станет молча брать картинки из чужих галерей.

Первая версия работает с конкретными карточками проектов. Общие статьи, поиск по всем темам сайта, видео и публикация в Instagram пока не реализованы. Сгенерированные факты перед публикацией проверяет редактор; автоматически гарантировать точность интерпретации плана моделью нельзя.

## Проверка без токенов

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python demo.py
```

Демонстрация использует сохранённые оригиналы «Сканди 78» и согласованный текст. Реальные запросы Telegram и OpenAI в офлайн-проверке не выполняются.

## Хранение и обслуживание

Данные — в постоянном Docker volume `bot-data`: SQLite, оригиналы, вложения брендов, версии PNG и очередь. Контейнер запускается без root и перезапускается при завершении процесса. Docker healthcheck показывает зависший/недоступный процесс; сам по себе статус unhealthy не перезапускает контейнер — для этого нужен внешний монитор.

Не запускайте несколько экземпляров с одним токеном. Не удаляйте volume при обновлении. Для согласованной резервной копии остановите контейнер и сохраните volume, затем запустите снова. Ключи из `.env` храните отдельно от резервной копии данных.

Журналы ограничены по размеру. Фотографии и архивы пока хранятся до ручной очистки: следите за свободным местом. Автоудаления исторических исходников нет, чтобы не сломать старые серии.

Обновление:

```sh
docker compose up -d --build
```

Ручная остановка:

```sh
docker compose stop
```
