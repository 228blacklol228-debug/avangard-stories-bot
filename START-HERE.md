## Шаг 1 — создать бота

1. Откройте официальный https://t.me/BotFather.
2. Отправьте `/newbot`.
3. Имя: например, `Авангард · Сторис`.
4. Придумайте свободное имя пользователя с окончанием `bot`. Доступность имени проверяет BotFather.
5. Сохраните выданный токен. Его нужно будет ввести на сервере; в общий чат его не отправляйте.
6. Для продолжения настройки достаточно сообщить имя вида `@имя_бота`.

## Шаг 2 — подключить текстовую модель

Первая версия использует OpenAI API для текстов, понимания правок и выбора существующих фотографий. Генерации изображений нет. Нужны доступный вашему аккаунту API, ключ и оплата API; эти данные пока не предоставлены. Если подходящего API-подключения нет, сначала выбираем доступную замену и адаптируем этот модуль, до покупки сервера.

## Шаг 3 — сервер

Пользователь выбрал бесплатный хостинг без привязки карты. Подготовлен режим webhook для Render Free с внешней очередью, снимком состояния и файлами в Supabase Free. Настоящее развёртывание ещё не выполнено; нужно подключить аккаунты и ключи.

GitHub Pages обслуживает статические сайты, а не этот Python-процесс. GitHub Actions ограничивает одно задание шестью часами; использовать его как бесконечный сервер текущего бота не планируется. GitHub можно использовать для кода и развёртывания.

Oracle Cloud Always Free предоставляет настоящие виртуальные машины в бесплатных пределах, поэтому архитектура текущего бота подходит. Для регистрации обычно требуется проверка карты, свободные мощности не гарантированы; простаивающие бесплатные машины могут изыматься. Перед выбором нужна проверка доступности регистрации для пользователя.

Render Free подходит для тестового веб-приложения, но засыпает после 15 минут без входящих запросов и теряет локальные файлы при остановке/перезапуске. Для него текущую версию необходимо адаптировать: приём сообщений через webhook, постоянная внешняя база и файловое хранилище. Нельзя обещать сохранность SQLite на локальном диске Render Free или запуск текущего пакета без изменений.
